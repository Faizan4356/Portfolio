SmokeGuard

Detects cigarettes and active smoking behavior in photos and video using a custom-trained YOLOv8 model, served through a FastAPI REST API with a React dashboard on top.

YOLOv8nFastAPIOpenCVPyTorchReactVite
Live demo View code
precision · recall shape
Problem

Manually reviewing surveillance footage for smoking violations in restricted areas doesn't scale, and generic object detectors aren't trained to recognize a lit cigarette or the act of smoking specifically.

Approach

Curated and labeled a custom dataset, fine-tuned YOLOv8n for cigarette/smoking detection, wrapped inference in a FastAPI service with OpenCV pre/post-processing, and built a React dashboard for live and batch review.

Result

A deployed REST API plus dashboard that flags smoking events in uploaded images and video in real time, usable as a drop-in moderation or compliance signal.

What I'd do differently

Add hard-negative mining for ambiguous cases — vaping, an unlit cigarette held near the mouth — since the model was trained on a fairly narrow custom set and likely overfits to it.

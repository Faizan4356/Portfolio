Sales / Demand Forecasting — Rossmann Store Sales

A time-series forecasting pipeline predicting daily store-level sales, comparing Prophet vs. XGBoost, then extended into a full Sales Intelligence Platform with LSTM anomaly detection, review sentiment analysis, and a combined Store Health Score.

ProphetXGBoost (RMSE 314)PyTorch LSTM AutoencoderSHAPStreamlit + Plotly
Live demo View code

XGBoost RMSE 314 vs. Prophet RMSE 403

Problem

Retail planning needs a store-level daily sales forecast that's both accurate and honest about its uncertainty — a single point estimate isn't enough for inventory decisions.

Approach

Benchmarked Prophet against XGBoost on the Rossmann dataset (XGBoost won, RMSE 314 vs. 403), added an 80% prediction interval via quantile regression, then layered in a PyTorch LSTM autoencoder for anomaly detection and a HuggingFace sentiment pipeline over synthetic reviews.

Result

A 5-tab Streamlit + Plotly app (Forecast, Upload Your Own Data, Store Health, What-If Simulator, Portfolio Overview) with a precomputed all-1,115-store view and an automated weekly Markdown alert report.

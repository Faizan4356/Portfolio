3D-StyleForge

An end-to-end demo that generates a 2D virtual try-on image (person + garment) and then converts that result into a web-ready 3D avatar (GLB) via the Hi3D / hitem3d.ai cloud API — with a React + Vite UI to upload, preview, generate, and view the 3D output.

FastAPIIDM-VTONHi3D APIReactVite
View code

image → gaussian/ply → glb

Problem

Virtual try-on demos usually stop at a flat 2D composite — there's no easy path from that image to something viewable as a 3D asset in a browser.

Approach

Chained an IDM-VTON-based 2D try-on adapter with a model-agnostic FastAPI endpoint that accepts a saved output, uploaded image, or base64/path input, then submits it to the Hi3D cloud API and polls an async job to download the resulting GLB.

Result

A React + Vite flow — upload, preview, generate, view — that produces a downloadable 3D avatar with no local GPU or model weights required in the default cloud-backed mode.

Excel-to-Dashboard

Turns any spreadsheet into an interactive, in-browser BI-style analytics dashboard — no backend, no upload, everything runs client-side. Auto-detects HR/attrition data vs. generic (sales, inventory, survey) data and adapts the entire dashboard accordingly.

Live demo View code
category breakdown
Problem

Non-technical teams have spreadsheets full of insight locked in rows and columns, but standing up a BI tool or backend just to visualize one file is overkill.

Approach

Parse the workbook entirely client-side with SheetJS, auto-detect whether it looks like HR/attrition data or a generic dataset, and render KPI cards, breakdown charts and a transparent, explainable attrition risk score — no server round-trip.

Result

A static, privacy-friendly dashboard generator with click-to-filter drill-down, CSV export, colorblind-safe palette, and dark/light theme — deployed as a GitHub Pages static site.

What I'd do differently

Surface a schema-detection confidence indicator — the HR-vs-generic auto-detection can misclassify an ambiguous spreadsheet today without telling the user it guessed.
